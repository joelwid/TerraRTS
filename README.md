# TerraRTS
Browser-native single-player economic RTS on a barren alien planet, inspired by Anno 1503. Target 20–30 minute matches; optimized ~15 minutes. Rocket launch is the sole victory.

Documentation only. Start with [AGENTS.md](AGENTS.md), then [game design](docs/GAME_DESIGN.md), [economy](docs/ECONOMY.md), [architecture](docs/ARCHITECTURE.md), [military](docs/MILITARY.md), [roadmap](docs/ROADMAP.md), and [testing](docs/TESTING.md). Numerical values are untested balancing seeds.
