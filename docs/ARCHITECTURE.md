# Technical architecture
Proposed TypeScript strict, Phaser 3, Vite, Vitest, HTML/CSS HUD. Static browser build, no backend. Pin dependencies and commit lockfile. npm scripts dev, build, preview, test, typecheck. Configure relative asset paths for subpath hosting. No public deployment by default.
Simulation owns authoritative state; UI submits validated commands and reads snapshots/events. Fixed 10Hz game tick, render independently with interpolation; pause stops simulation, 2x doubles ticks per real second. Deterministic IDs and iteration; no wall-clock timers in gameplay. Logical XY coordinates, projection sx=(x-y)*32, sy=(x+y)*16; inverse x=sx/64+sy/32, y=sy/32-sx/64 after camera transform. Depth sort by footprint front edge and unit position; test overlap.
Suggested modules src/sim/{clock,world,territory,inventory,construction,production,population,upgrades,recruitment,combat,aliens,victory,stats}, src/render, src/ui, src/input, src/data, tests. JSON definitions for buildings, units, progression, rocket, fixed map. Validate definitions at load. Generic building lifecycle and specialized behaviors. Commands place/cancel/demolish/upgrade/pauseProduction/recruit/cancelRecruit/move/attack/attackMove/repair/rocketStage. Atomic validation and payment. Recalculate claims on Hub changes, invalidate navigation on occupancy changes. Headless simulation imports no DOM/Phaser. Use shared rules for preview and execution. No hidden deposit leaks via UI before scan.
