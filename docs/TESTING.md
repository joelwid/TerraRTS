# Acceptance and test plan
Unit tests: projection roundtrip; map validity; exact deposit ID and footprint; claim overlap and loss; persistent scan/fertility; atomic costs/refunds; no negative resources; deterministic production and shortages; population unlock persistence; upgrade timing; recruitment queue/cancel; pathfinding obstacles; damage matrix; nest reward exactly once; rocket stage ordering; pause and speed equivalence; restart resets all state.
Integration: fresh start can bootstrap wood/iron/tools; all eight resources producible; build all 15 types; no information leak before scan; no overlapping occupancy; territory loss disables production; reclaim restores; all units controllable; alien attacks local; tower defense; starting Hub defeat; rocket victory stops simulation. Test simultaneous transactions and destruction during construction/upgrade/recruitment.
Headless simulator uses same definitions and rules, records time series and build orders. Test focused economic rush ~15–20 min, normal mixed 20–30 min, low-pop horizontal, compact vertical, military expansion, peaceful no combat, recovery from poor placement and shortages. Compare actual times and investment payback; tune costs, rates, map and thresholds. No claim of balance without evidence.
Browser smoke: npm ci, typecheck, tests, production build, run preview, verify camera/selection/HUD and complete match. Target desktop mouse/keyboard, responsive HUD, smooth rendering on typical hardware; record actual browser/performance results. No critical crashes, resource duplication or permanent accidental economic lockout in tested routes. All 15 buildings, eight stocks, three units, fixed map, static visual states and rocket win required for full v0.1.
